# スロット高設定挙動検出アプリ

店舗WiFi限定のデータサイト(athink.jp / ガーデン川口安行)からスロットの台データを収集し、
蓄積したデータから高設定挙動の台を探すアプリ。

## 全体構成

```
[店内・iPhone]                    [クラウド]                [どこでも・iPhone]
データサイトを開く                GAS + スプレッドシート      分析PWA
  ↓ 収集ブックマークレット実行      台番号×日付×時刻で         高設定候補を
  対象機種の全台を自動巡回 ─POST─▶  スナップショット蓄積 ──▶  スコア化して表示
```

サイト解析の結果、データサイトはAJAXで各画面を取得するSPAだと判明。
ブックマークレット1回のタップで以下を自動巡回できる:

1. `kishu_list.php` … 機種一覧(機種番号・貸玉区分)
2. `dai_list.self.php` … 機種ごとの台番一覧(ページング対応)
3. `dedama.php` … 台ごとの BB / RB / ゲーム数 / BB確率 / RB確率 / 合成確率 /
   最大持玉 / 累計スタート / 大当り履歴(時刻・スタート・出玉・種別)

※ 大当り履歴はサイト側が1時間に1回更新。上部カウンターはより高頻度。

## セットアップ手順

### 1. GAS(バックエンド)のデプロイ ※初回のみ

1. [Googleスプレッドシート](https://sheets.new)を新規作成(名前例:「スロットデータ」)
2. メニュー「拡張機能」→「Apps Script」
3. `gas/code.gs` の内容を貼り付けて保存
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **全員**
5. 発行された「ウェブアプリのURL」(`https://script.google.com/macros/s/…/exec`)をコピーしておく

### 2. 収集ブックマークレットの登録 ※初回のみ

1. Safariで適当なページをブックマーク登録(名前:「スロット収集」など)
2. ブックマークを編集し、URL欄を `collect/collector.bookmarklet.txt` の1行に丸ごと置き換え

### 3. 店内での収集(毎回)

1. 店舗WiFiに接続してデータサイト(top.php)を開く
2. 「スロット収集」ブックマークをタップ
3. 初回のみGASのウェブアプリURLを聞かれるので貼り付け(2回目以降は記憶される)
4. 画面に進捗ログが出て、対象機種の全台を自動巡回→GASへ送信
   (既定はジャグラー系 約120台、1〜2分程度)

- 対象機種の変更: Safariのコンソール等で
  `localStorage.setItem('slot_kishu_filter','ジャグラー|ハナビ')` のように正規表現で設定
- 1日に何回実行してもOK。大当り履歴は重複排除して蓄積される

## データの持ち方(スプレッドシート)

- `snapshots` … 収集1回×1台=1行。BB/RB/確率/累計スタートなどのその時点の値
- `history` … 大当り1回=1行。(日付|台番|大当り番号)で重複排除

## 分析指標(次のステップ)

機種ごとの設定差データと突き合わせてスコア化する:

- RB確率・合成確率(ジャグラーは特にRBに設定差が大きい)
- 累計スタート(試行数)を使った信頼区間の重み付け
- 大当り履歴からの時間帯別ペース・差枚推定
- 前日データとの突合(据え置き・上げ狙いの挙動)

機種別の設定1〜6の数値は slolaboratory(会員サイト)から対象機種分を転記して
`machines.json`(予定)に登録する。

## ファイル構成

- `collect/collector.source.js` … 収集ブックマークレットの読みやすい版(開発用)
- `collect/collector.bookmarklet.txt` … 登録用の1行(terserでminify済み)
- `collect/copy-html.source.js` / `copy-html.bookmarklet.txt` … HTMLサンプル取得用(解析用)
- `gas/code.gs` … GASバックエンド(doPost=収集受信 / doGet=分析用API)
- `samples/dedama-sample.html` … 台詳細ページの実サンプル(パーサー検証用)
