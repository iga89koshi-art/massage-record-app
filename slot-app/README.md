# スロット高設定挙動検出アプリ

店舗WiFi限定のデータサイト(athink.jp)からスロットの台データを収集し、
蓄積したデータから高設定挙動の台を探すアプリ。

## 全体構成

```
[店内・iPhone]                    [クラウド]                [どこでも・iPhone]
データサイトを開く                GAS + スプレッドシート      分析PWA
  ↓ ブックマークレット実行          台番号×日付×時刻で         高設定候補を
  ページからデータ抽出   ──POST──▶  スナップショット蓄積 ──▶  スコア化して表示
```

- **収集**: データサイトは店舗WiFi内からしか見えないため、収集は必ずスマホ側で行う。
  店内でデータサイトを開き、Safariのブックマークレットをタップして送信する。
- **蓄積**: Google Apps Script (GAS) のWebアプリが受け取り、スプレッドシートに保存。
  既存のマッサージ記録アプリと同じ構成。
- **分析**: PWAが履歴データを読み、機種ごとの設定差指標で高設定候補をスコア化。

## HTMLコピー用ブックマークレット(サンプル取得用)

iPhoneのSafariでの登録方法:

1. 適当なページをブックマークに追加する(名前は「HTMLコピー」など)
2. ブックマーク編集画面を開き、URLを下の1行に丸ごと置き換える
3. 店内でデータサイトを開いた状態でこのブックマークをタップ
4. 画面に出る「HTMLをコピー」ボタンを押す → クリップボードにページのHTMLが入る
5. コピーした内容をClaudeのチャットに貼る(長い場合はGoogleドキュメントに貼ってもOK)

ブックマークレット本体は `collect/copy-html.bookmarklet.txt` にある。

**取ってきてほしいページ**(それぞれ別々にコピー):
- 台一覧ページ(全台の一覧が見えている状態)
- どれか1台の詳細ページ(グラフや履歴が見えている状態)

## 分析指標(予定)

機種ごとの設定差データ(`machines.json` 予定)と突き合わせてスコア化する。
データサイトから取れる情報に依存するが、候補は:

- ボーナス合算確率 / BB確率 / RB確率(特にRBは設定差が大きい機種が多い)
- 総ゲーム数(信頼区間の重み付けに使用)
- スランプグラフの傾向(取得できれば差枚推定)
- 日をまたいだ据え置き・上げ狙いの挙動(前日データとの突合)
- 時系列スナップショットからの当日ペース変化

具体的な機種別の数値(設定1〜6の確率など)は slolaboratory の判別情報を
参考に登録する(会員サイトのため、必要な機種の数値は手動で転記する)。
