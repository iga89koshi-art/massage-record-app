# 施術記録 → Instagram企画

日々の施術記録・現場のメモを、リールの企画に変換する。
**死因対策**: 治療院系Instagramの失敗理由の第1位は「投稿頻度が落ちる」。
ネタ切れで止まるのを、本業から自動供給することで防ぐ。

関連ファイル（企画の枠組みはここで定義されている。必ず参照する）:
- `instagram/02-最初の30本.md` — 柱の分類（A〜G）と共通ルール
- `instagram/03-顔出し段階設計.md` — 顔出しレベル 0〜3
- `instagram/00-戦略記録.md` — 誰に向けているか、何を狙っているか

---

## 絶対に守る2つの制約

### 1. 患者が特定できる形にしない

これは医療記録である。**1件の記録をそのまま企画にしない。**

- **複数の記録から共通項を抜き、「よくあるパターン」に変換する**
- 個人が特定できる要素は全て落とす:
  氏名、地名（市区町村より細かいもの）、施設名、医療機関名、
  年齢は「80代」まで、日付は「先週」程度、家族構成の具体、珍しい疾患名の組み合わせ
- 「1人しかいないような事例」は、どれだけ良いネタでも使わない

**この抽象化は、privacy対策であると同時にコンテンツとしても強い。**
視聴者が反応するのは「うちの親と同じだ」という一致度なので、
個別の症例より「よくあるパターン」の方が刺さる。

### 2. あはき法の広告規制

投稿が「広告」と判定されるのは、**誘引性・特定性・認知性の3つ全部**を満たしたとき。
**特定性を外す**運用にしているので、以下を守る。

- ❌ 「治る」「改善する」「効果があります」「良くなります」
- ❌ ビフォーアフター、断定的な体験談
- ❌ 院名・所在地を出したうえで効果を語る
- ⭕ 制度・保険・対象疾患の事実としての説明（告示の範囲）
- ⭕ 個人として「訪問マッサージという仕事」を語る
- ⭕ 「対象になり得る」「制度上こうなっている」という書き方

**判断に迷ったら、効果の話を制度の話に置き換える。**
（例: 「拘縮が良くなった」→「関節拘縮は療養費の対象疾患に含まれる」）

## 手順

### 1. 材料を受け取る

施術記録のメモ、口頭の報告、その日あった出来事など。形式は問わない。
まとまった量（1〜2週間分）があると共通項が抜きやすい。

### 2. 素材を3種類に仕分ける

| 種類 | 中身 | 化けやすい柱 |
|---|---|---|
| **繰り返し出てくる状況** | 複数の患者に共通する状態・場面 | B 判定 / F 気持ち |
| **家族から実際に聞かれたこと** | 質問、勘違い、不安 | C お金 / D 同意書 / E 誤解 |
| **制度・手続きで起きたこと** | 同意書のやりとり、ケアマネとの連携、更新 | D 同意書 / A 存在 |

**「家族から実際に聞かれたこと」が最も価値が高い。**
実際に出た質問は、同じ疑問を持つ人が必ず他にもいる。一次情報そのもの。

### 3. 企画に変換する

1件につき、次の形で出す。

```
【企画】<内容が一行で分かるタイトル>
柱        : A〜G のどれか
顔出し    : 0〜3（今の段階に合わせる。迷ったら現在の段階のまま）
形式      : リール / カルーセル / ストーリーズ
尺        : 15〜30秒
冒頭フック: 「<実際に喋る/表示する1行目>」
構成      : 1. ... 2. ... 3. ...（3〜4ステップ）
締め      : 保存を促す / シェアを促す のどちらか
狙い      : リーチ / 保存 / シェア / 転換 / 信頼 / 採用
規制チェック: OK（懸念があれば具体的に何を落としたか書く）
元ネタ    : どの記録から起こしたか（抽象化前の参照。投稿には出さない）
```

### 4. 出す本数

依頼がなければ **5本**。多すぎると選ぶだけで疲れて、結局出さなくなる。
柱が偏らないように散らす。

---

## 冒頭フックの作り方

**完全視聴率が2026年アルゴリズムの最重要指標**なので、1秒目で決まる。

- 挨拶・自己紹介から入らない。**絶対に**
- 結論か、意外な事実から入る
- 相手を名指しする（「〜という方へ」「〜と思っていませんか」）
- 数字があれば前に出す（「9割が知りません」）

**弱い例**: 「今日は訪問マッサージについてお話しします」
**強い例**: 「介護保険の限度額、もう使い切ってませんか」

---

## 誰に向けているか（毎回思い出す）

- **40〜50代の子世代**。親に**訪問医が入っている**、寝たきり・歩行困難な状態
- 心理: 疲弊、罪悪感、孤立、相談先が分からない
- **57.7%が「可能な限り自宅で介護を受けさせたい」** と思っている
- つまり **意志はある。手段を知らないだけ**
- そして **潜在ニーズ層の約9割が、この制度の存在を知らない**

刺さるのは施術の気持ちよさではなく、**「これ、うちの親と同じだ」という一致度**。
そして最終的に効くのは **同意書の取り方** — ここが転換の核。

---

## ネタが本当に無いとき

記録に何も無い週は、次から起こす。全て症例ゼロで作れる。

- 制度の中で、家族が誤解しやすい点（介護保険との別枠、要介護認定との無関係、往療費）
- 令和8年7月改定で変わったこと
- 同意書の実務（依頼の仕方、更新、断られる理由）
- 訪問診療 / 訪問看護 / 訪問リハ / 訪問マッサージ の違い
- 1日の動き方、この仕事を続けている理由（採用軸）

**採用軸は5本に1本の割合で混ぜる。** 25人／施術者の上限があるため、
集客が伸びてから採用を考えると、一番おいしい時期を取りこぼす。

---

## 出したあと

企画を採用して投稿したら、`instagram/01-記録の器/投稿ログ.csv` に
**No / 投稿日 / 形式 / 顔出しレベル / 柱 / テーマ / 冒頭フック** を先に記録する。
数字は48時間後に追記する。

**フックの文言だけは、その場で残さないと再現できない。**
