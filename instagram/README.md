# 訪問マッサージ × Instagram 直接集客

業界の紹介経路の8〜9割はケアマネ経由で、直接集客の成功例が存在しない領域。
そこに、**訪問医がすでに入っている患者の家族（40〜50代）**へ向けて入る。

出口は2段構え。

| | 内容 |
|---|---|
| **A** | 地域で直接集客を成立させる → 患者増・採用 |
| **B** | Aの再現方法を商品化して同業者に売る |

**BはAの副産物であり、Aを走る過程そのものがBの素材になる。**
だから記録を先に用意する。

## 順番

1. **`01-記録の器/` の3つのCSVをスプレッドシートに入れる** ← 1本目を出す前に
2. `02-最初の30本.md` のフェーズ1（#1〜8、顔なし）を出しきる。週3本で約3週間
3. 数字を見て `03-顔出し段階設計.md` の基準でフェーズ2へ
4. 週次サマリの「今週の気づき」を毎週埋める ← **講座の本文になる部分**
5. ネタが尽きたら `insta-neta` スキルを呼ぶ

---

## 先に潰したい未検証の前提

`00-戦略記録.md` の第6節に一覧。特に上の2つ。

1. **商圏（越谷+16km）で訪問医が入っている患者の実数** — 天井が見える
2. **現在の空き施術枠** — 埋まっているなら集客より先に採用

## 忘れないこと

**最初の2ヶ月は二度と再現できない。**
ネタがなく、フォロワーがゼロで、手探りの時期。ここが講座の一番おいしい中身になる。
順調に回り出してから思い出して書いたノウハウは、因果が失われていて売り物にならない。

**うまくいかなかった週ほど詳しく書く。** 買い手が本当に知りたいのは失敗の処理の仕方。
