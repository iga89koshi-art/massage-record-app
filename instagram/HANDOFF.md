## 0. 誰の、何のプロジェクトか

**五十嵐鍼灸院（訪問マッサージ）の経営者**が、
**Instagramで患者を直接獲得する**新規施策を立ち上げようとしている。

本人は施術者であり経営者。エンジニアではないが、
**Claude Code / Notion / GAS を使って本業の事務作業を自力で自動化済み**
（施術記録の取り込み、月次の施術内容報告書、レセコン→Notion同期、請求書処理）。
そこで空いた時間を、新規事業ではなく**自分の事業の伸長に再投資する**という判断でこの施策に至った。

このリポジトリ自体が、その自動化資産（施術記録アプリ：GAS + PWA）。

## 1. 絶対に間違えてはいけない前提

**新しいエージェントが最も間違えやすい箇所。** 実際に前のセッションで全部間違えて、本人に訂正された。

| ❌ 誤り | ⭕ 正しい |
|---|---|
| 訪問マッサージは介護保険 | **医療保険（療養費）**。介護保険ではない。介護事業所向けの話は的外れ |
| 本人は介護士 | **違う**。施術者（あん摩マッサージ指圧）であり経営者 |
| 訪問看護のドメイン知識がある | **ない**。訪問看護はやっていない。同意書と訪問看護指示書は別物 |
| 鍼灸院の多くが訪問をやっている | **やっていない**。訪問をやっている鍼灸院は少数 |
| SNSは広告規制で厳しく制限される | **越谷保健所に本人が直接確認済み**。少なくとも越谷ではwebは広告規制の対象外。ただし効果効能と特定性は引き続き避ける運用 |
| 同意書は医師が書いてくれない大きな壁 | **訪問医ならほぼ100%書く**。医師が断るのは「同一病名で保険診療と併用できず自院の売上が減る」ケースで、訪問医が既に入っている患者ではこの利益相反が起きない |

**最後の行が本戦略の核心。** ターゲットを「訪問医が既に入っている患者の家族」に絞ることで、
業界最大の障壁を構造ごと回避している。

## 2. 位置づけ ← 最も誤解されやすい。ここを間違えると提案が全部ずれる

**集客の柱は、あくまでケアマネ営業。Instagramは柱ではない。**
Instagramは「集客の施策として試してみる」実験であって、ケアマネ営業を置き換えるものではない。
本人の営業時間を柱から奪ってまでやるものではない、という前提で提案すること。

### 実験が成功したときに得られるもの（この順で価値がある）

1. **求人** — やりがい軸で刺さる層に届く。施術者が増えれば柱の受け皿が増える
2. **実績** — 「Instagramを活用して、訪問マッサージというアナログなビジネスを伸ばした」という売り物
3. 患者の直接獲得そのもの

**2を成立させるには、伸びた分がInstagram由来だと示せる必要がある。**
ケアマネ営業と並走している以上、流入元を分けて記録していなければ「増えたが因果は言えない」で終わる。
→ 紹介DBの流入元と経過を、投稿を始める前から埋めること。

### 実験としての内容

**訪問マッサージの患者を、Instagramで直接獲得できるか試す。**
業界の紹介経路の8〜9割はケアマネ経由で、直接集客の成功例が存在しない領域。

- **狙う相手**: 患者本人ではなく **家族（40〜50代の子世代）**。患者は高齢者でInstagramにいない
- **さらに絞る**: **訪問医がすでに入っている**寝たきり・歩行困難な人の家族
- **導線の核**: 施術の気持ちよさではなく **「同意書の取り方」**
- **アカウント**: 個人名義。院の宣伝はしない
- **副産物**: 求人（やりがい軸で刺さる層）と、将来の講座

### 出口は2段構え

| | 内容 | 時間軸 |
|---|---|---|
| **A** | 地域で直接集客を成立させる → 患者増・採用 | 6〜12ヶ月 |
| **B** | Aの再現方法を商品化して同業者（あはき系 約56,700施設）に売る | Aの成功後 |

**BはAの副産物。Aを走る過程そのものがBの素材になる。**
だから記録を最初から取る。**この2つを1つのアカウントに混ぜない。**

### やめる条件（実験である以上、先に決めておく）

柱ではないので、成果が出ないまま惰性で続けるのが一番損。**撤退ラインは投稿を始める前に決める。**
まだ未定。決めたらここに書く。目安として決めるべきもの:

- 何ヶ月／何本まで試すか
- その時点で何が起きていなければ畳むか（例: 完全視聴率、商圏内フォロワー比率、問い合わせ件数）
- 本業の営業時間を何時間まで使ってよいか（**これを超えたら柱を削っている**）

> 2026年のボトルネックは市場サイズではなく**配布**。

## 7. 作業時に必ず守る制約

### あはき法（広告規制）

「広告」判定は**誘引性・特定性・認知性の3つ全部**を満たしたとき。**特定性を外す運用**。

- ❌ 「治る」「改善する」「効果があります」
- ❌ ビフォーアフター、断定的な体験談
- ❌ 院名・所在地を出したうえで効果を語る
- ⭕ 制度・保険・対象疾患の事実としての説明
- ⭕ 個人として「訪問マッサージという仕事」を語る

迷ったら**効果の話を制度の話に置き換える**。

### 患者情報

施術記録は医療記録。**1件をそのまま公開コンテンツにしない。**
複数の記録から共通項を抜き、「よくあるパターン」に抽象化する。
氏名・詳細な地名・施設名・医療機関名・珍しい疾患の組み合わせは落とす。

この抽象化はプライバシー保護であると同時に、
視聴者が反応するのは「うちの親と同じだ」という一致度なので**コンテンツとしても強い**。

本人は**同意より反証を求める**。前セッションでは、本人が事実誤認を7回訂正して戦略が固まった。

- 提案には根拠となる数字と出典を付ける
- 賛成一辺倒にならない。死因を先に挙げる
- ただし本人が一次情報（保健所への確認、現場の実務）で反証したら、それが正しい
- 本人は現金が必要な状況にあるが、キャッシュの話は「一旦置く」と本人が判断済み

## 9. 未解決の論点

- **属人性**: 本人の成功要因が「持ちネタの量」（現場・症例・歴）である場合、
  開業したての買い手は再現できない。→ Bには「ネタゼロから始められる型」が必須。
  30本すべてを症例ゼロで作れる設計にしたのはこのため
- **買い手の実像**: 講座の主力購買層は「開業する自信のある人」ではなく
  「売上が伸び悩んでいる人」。人前に出るのが苦手な層である可能性が高い。
  → 顔出しの段階設計はこの層のために作られている
- **将来の訪問看護参入**: 本人が構想しているが、人員基準（看護師2.5人以上、管理者も看護師）があり、
  成否は看護師の採用に依存する。**「名前が売れたから」ではなく「看護師が採れる目処が立ったから」で判断すべき**
