推計の手順:

### すでに競合が取っている分

**訪問診療患者のうち、あん摩マッサージ療養費を受けているのは約20%。**
全国20.5%・埼玉県19.2%で一致するので、この比率は信用してよい。

- 東部医療圏の居宅3,760人 × 20% ≒ **760人が施術中、約3,000人が未開拓**
- 越谷市内では約460人が施術中
- 越谷市の出張専門あん摩事業所は19件 → 単純割りで1社24人。市外業者も入るので実際はもっと少ない

出典: 厚労省「医療保険に関する基礎資料（令和5年度）」p.33 https://www.mhlw.go.jp/content/kiso_r05.pdf

### この推計の弱点（引用時は必ず一緒に）

1. **NDBの二次医療圏は「医療機関の所在地」ベースで、患者の住所地ではない。**
   「東部医療圏3,760人」は東部の在宅医が診ている患者数。越谷市民が足立区のクリニックにかかっている分は入らない。
   → 在宅医への営業が入口である以上、実務的にはむしろこの定義のほうが正しい
2. 年間ユニーク値→月次変換に全国シェアを使っている。±10%は見る
3. 市町村按分は65歳以上人口比の按分にすぎない
4. 16km圏フル（足立・葛飾北部）は面積カバー率の目分量按分で、ここだけ精度が明確に低い
5. **最も重要**: 「訪問診療医が入っている患者」＝同意書が取れる人、ではない。
   マッサージの同意書は**外来のかかりつけ医でも出せる**。
   つまりこの天井は「訪問医が入っている家族を狙う」という**今の施策の天井であって、事業全体の天井ではない**。
   逆側の母数（越谷市の要介護3以上5,409人）で見れば、訪問診療が入っていない層のほうが数としては大きい。

**ただし受け皿は偏っている。** 長谷川が22/25でほぼ満床、残り4名で21人。

### 現在の患者43人は、全員ケアマネ由来

**ベースラインが100%ケアマネ**ということ。
これはInstagram実験にとって好都合で、**Instagram経由の患者が1人でも出れば、それがそのまま実績になる。**
流入元を分けるための仕組みは不要。

### 参考: 既存チャネルの転換率データが存在しない（ケアマネ営業側の話。Instagramの前提条件ではない）

紹介データベースには「問い合わせ → 体験日程調整中 → 体験実施 → 同意書取得中 → 施術開始 / 不成立」の
ファネル項目があるが、**27件すべてが「施術開始」**（2019-08〜2026-08）。
成功したものだけを後から登録している状態で、**落ちた分が記録されていない。**

つまり **ケアマネ経由の転換率という比較対象が、今は存在しない。**
Instagram側の `01-記録の器/転換ログ.csv` だけ埋めても「その数字が良いのか悪いのか」を判定できない。

→ **紹介DBの「経過」を、今日から不成立も含めて埋める運用にする。** 器はすでにNotion側にある。

## 3. この数字が戦略に返すもの

- 天井3,500〜4,000人に対して現在43人。**枠が埋まって困る局面は当分来ない。** 集客を止める理由がない
- 競合が取っているのは2割。**8割が未開拓**という状況は、直接集客の成功例が存在しないという前提と整合する
- LTV 77万円 × 転換率0.1% の計算は全国リーチ前提だった。
  **商圏内3,000人の未開拓層に対しては、全国リーチではなく地域リーチの効率が効く。**
  → `00-戦略記録.md` 第6節-5「商圏外フォロワーの比率」の重要度が上がった
- 弱点5が示す通り、**「訪問医が入っている家族」への絞り込みは、天井を1/5に狭めている**可能性がある。
  外来のかかりつけ医しかいない層まで広げれば母数は5,409人（越谷市のみ）まで伸びる。
  ただし絞り込みの目的は母数ではなく**「同意書を断られない」という障壁回避**なので、
  立ち上げ期は絞ったまま走る。**広げるかどうかは、転換ログに離脱理由が溜まってから判断する。**
