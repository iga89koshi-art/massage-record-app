# 記録の器

3つのCSVをGoogleスプレッドシートにインポートして使う。
（スプレッドシート → ファイル → インポート → アップロード → 「新しいシートを挿入」）

**この記録が、講座（商品B）の価値の大半を決める。**
順調に回り出してから思い出して書いたノウハウは売り物にならない。
「なぜ伸びたか」の因果が失われるため。

---

## ファイル

| ファイル | 何を記録するか | 頻度 |
|---|---|---|
| `投稿ログ.csv` | 全投稿の内容と数字 | 投稿ごと＋48時間後に数字を追記 |
| `転換ログ.csv` | 問い合わせ → 同意書 → 初回施術 | 問い合わせが来たとき＋進捗があったとき |
| `週次サマリ.csv` | 週単位の集計と気づき | 週1回 |

---

## 最低限これだけは（時間がない日）

投稿ログの **No / 投稿日 / 顔出しレベル / 柱 / 冒頭フック** を先に入れておく。
数字は後からまとめて追える。**フックの文言だけは、その場で残さないと再現できない。**

---

## 数字の取り方

Instagramの投稿 → インサイトを表示。**投稿から48時間後**に記録する（初速がほぼ確定する）。

| 項目 | どこで見るか | なぜ重要か |
|---|---|---|
| **完全視聴率** | リールのインサイト（視聴維持率／平均視聴時間÷尺） | **2026年アルゴリズムの最重要指標** |
| **シェア（送信）** | インサイトの「シェア」 | フォロワー外リーチを最も左右する |
| **保存** | インサイトの「保存」 | 情報価値の指標。制度系コンテンツはここで測る |
| リーチ / フォロワー外率 | インサイト上部 | 拡散したかどうか |
| プロフ遷移 | インサイト下部 | 「興味を持った」の最短シグナル |

**いいねは無視してよい。** 完全視聴率・シェア・保存の3つを見る。

## 顔出しレベル（`03-顔出し段階設計.md` と対応）

| レベル | 内容 |
|---|---|
| 0 | 顔なし。図解・テロップ・資料のみ |
| 1 | 手元・後ろ姿・声のみ |
| 2 | 横顔・部分的に映る |
| 3 | 正面・語り |

**レベル0と3で同じテーマを撮り、数字を比較する。**
顔なしでも勝てるかが、講座が商品として成立するかを決める。

## 柱（コンテンツの分類・`02-最初の30本.md` と対応）

| 記号 | 柱 | 狙い |
|---|---|---|
| A | 存在を知らせる | リーチ |
| B | 対象判定（うちの親は該当する？） | 保存・シェア |
| C | お金の話 | 保存 |
| D | 同意書 | **転換** |
| E | 誤解を解く | シェア |
| F | 家族の気持ち | 共感・コメント |
| G | 中の人 | 信頼・フォロー |

## 転換ログで一番大事な列

**`きっかけ投稿No`**。

どの投稿が実際に金を生んだかが分かるのはここだけ。
問い合わせが来たら「何を見て連絡をくれたか」を必ず聞いて記録する。
バズった投稿と、患者を連れてきた投稿は**一致しないことが多い**。

## 週次サマリの `今週の気づき` 欄について

**ここが講座の本文になる。**

数字は後から集計できるが、「なぜそう判断したか」は今しか書けない。
うまくいかなかった週ほど詳しく書く。買い手が本当に知りたいのは失敗の処理の仕方。
