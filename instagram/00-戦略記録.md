# 戦略記録 — 訪問マッサージ × Instagram 直接集客

最終更新: 2026-08-14

このファイルは**講座（商品B）の原資**である。
順調に回り出してからでは、立ち上げ期の判断過程は二度と再現できない。
「なぜそう決めたか」を、結果が出る前に書き残しておくためのもの。

---

## 1. 確定した戦略

**訪問マッサージの患者を、Instagramで直接獲得する。**
業界の紹介経路の8〜9割はケアマネ経由で、直接集客の成功例が存在しない領域。

- **狙う相手**: 患者本人ではなく **家族（40〜50代の子世代）**
- **さらに絞る**: **訪問医がすでに入っている**寝たきり・歩行困難な人の家族
- **導線の核**: 施術の気持ちよさではなく **「同意書の取り方」**
- **アカウント**: 個人名義。院の宣伝はしない（あはき法対策 兼 発信の自由度確保）
- **副産物**: 求人（やりがい軸で刺さる層）と、将来の講座の実績

### 出口は2段構え

| | 内容 | 時間軸 |
|---|---|---|
| **A** | 地域で直接集客を成立させる → 本業の患者増・採用 | 6〜12ヶ月 |
| **B** | Aの再現方法を商品化して同業者に売る | Aの成功後 |

BはAの副産物であり、Aを走る過程そのものがBの素材になる。
**この2つを1つのアカウントに混ぜない**（客層が違う）。Aで実績を作り、別チャネルでBを売る。

## 2. ここに至るまでに却下した選択肢

記録しておく理由: 後で「あれをやればよかった」と思ったとき、一度検討して落としたことを思い出せるように。

| 却下した案 | 却下の理由 |
|---|---|
| 訪問マッサージ向けレセコン・SaaS | spotlog等の専用ソフトが6年稼働、相場は月3,850円。後発が入る余地なし |
| 介護事業所（20万事業所）向けツール | 医療保険ではなく介護保険。ドメイン知識が効かない |
| 訪問看護向けの記録・報告書AI | **本人が訪問看護をやっていない**。同意書と指示書は別物。丸腰になる |
| 建設業（48万業者）など大きい市場 | 業界知識ゼロ。TAMが26倍でもリーチ率が0.01%なら取れる数は10分の1以下 |
| 英語圏SaaS | 唯一の武器（日本の療養費の現場知識）が価値ゼロになる |
| AI記事量産・情報商材（初期案） | AIラッパーの60〜70%が収益ゼロ。90%が2026年内に消滅見込み |

### 却下の過程で得た原則

> **TAM を増やすより、リーチできる率を上げる方が効く。**
> ミクロSaaSの70%が月$1,000未満で死ぬのは市場が小さいからではなく、顧客に届かないから。
> 2026年のボトルネックは市場サイズではなく **配布**。

Instagram はその配布そのものであり、だからこの案は「話が逸れた」のではなく
**ずっと足りていなかったピース**だった。

```
売上上限 = 施術者数 × 25人 × 月3万円
→ 施術者1人なら年900万で頭打ち
```

## 4. 検証した仮説と、その修正履歴

この節が講座の中身に一番近い。**間違った仮説とその修正過程**こそが価値。

### 仮説1: 「9割ケアマネ経由 → Instagramは構造的に無理」
**却下。** 逆だった。
全員が1本の細い管を通っている＝全員が同じケアマネの前で同じ営業をしている。
**2本目の管を持った者が独占する。**
業界側の文献も既に「直接集客 → 担当ケアマネ営業 → さらなる集客」の流れが必要だと書いており、
**答えは業界内で出ていて、誰も実行できていない**状態だった。

### 仮説2: 「認知9割ゼロだからチャンス」
**表層だった。** 本当の理由は**単価**。
LTV 77万円だから転換率0.1%で成立する。他のローカルビジネスでは真似できない構造。

### 仮説3: 「同意書が最大の死因」
**本人の一次情報で解決。** 訪問医ならほぼ100%書く。
医師が断る理由は「同一病名で保険診療と併用できず、自院の売上が減るから」だが、
**訪問医が入っている患者に絞れば、その利益相反が発生しない。**
→ ターゲティングで構造問題を回避した。これが本戦略の核心。

### 仮説4: 「A（顔出し集客）とB（講座）は同じアカウントで両立しない」
**部分的に正しいが、モデルの読み違い。**
指摘したのは「1アカウントに2客層を混ぜると死ぬ」という話。
実際のモデルは **Aで勝つ → その実績がBの商品になる** という逐次型なので混ざらない。

### 仮説5: 「顔で成功したノウハウは、顔がない人に売れない（属人性リスク）」
**ほぼ解消。ただし理由が当初の想定と違う。**

- 誤: 「顔じゃなくても優しそう・声・笑顔で売れる」
- 正: **そもそも高い魅力を要求されていない。** 高齢者宅に上がる仕事であり、必要なのは
  「家に上げられる人か」の信頼の閾値を超えること。閾値は低く、しかも**上限がある**
  （盛りすぎは逆効果というデータ）。
- 差がつくのは魅力ではなく **出すか出さないか**。これは100%再現可能。

### 仮説6: 「属人性リスクは消えた」
**消えていない。移った。**
本当の非再現要素は顔ではなく **持ちネタの量**（現場・症例・同意書の実績・歴）。
開業したての買い手は初日、患者ゼロ。
→ **Bには「ネタゼロから始められる型」が必須。**

### 仮説7: 「買い手は開業する人＝自分に自信がある層」
**修正。** 売り先の定義は「これから開業する人**や、売上が伸び悩んでる人**」。
後者は自信がある層ではなく、むしろ人前に出るのが苦手だから伸び悩んでいる可能性が高い。
そして**講座に金を払う主力はこちら。**
→ Bには「顔出しの閾値を段階的に下げる手順」が必須。

## 5. 死因リストと対処状況

| # | 死因 | 状態 | 対処 |
|---|---|---|---|
| 1 | 同意書が取れず、バズっても1円にならない | **解決** | 訪問医が入っている患者に絞る |
| 2 | 投稿頻度が落ちて止まる（統計的に最多） | **要対処** | AI による材料増幅（→ skill）。本業の記録から企画を自動生成 |
| 3 | 属人性（顔）でBが売れない | **ほぼ解消** | 閾値が低く上限もある。差は「出すか否か」 |
| 4 | 属人性（材料）でBが売れない | **要対処** | 立ち上げ期＝ネタゼロ期の動き方をそのまま商品化 |
| 5 | 25人の壁。集客だけ成功しても年900万で頭打ち | **要対処** | 採用軸を最初からアカウントに埋め込む |
| 6 | 地理的希釈（全国リーチの98%が患者にならない） | **解決** | LTVが吸収。商圏外は同業者・採用に転換 |
| 7 | あはき法違反 | **管理下** | 越谷保健所に確認済み（web は広告規制対象外）。院を特定させず効果効能を謳わない運用を継続 |

### 死因5について（重要）

**求人は「付随してくるもの」ではなく、先にボトルネックになる。**
25人埋まった時点で次の問い合わせは断るか待たせるしかなく、集客の成果がそのまま捨てられる。
Instagramが伸び始めてから採用を考えると、一番おいしい時期を取りこぼす。

## 6. 未検証の前提（これから潰す）

いま戦略が乗っている、まだ確かめていない仮定。優先度順。

1. **商圏内で訪問医が入っている患者の実数**
   → 越谷+16km圏の在宅療養支援診療所（厚生局が届出リストを公開）から逆算できる。
   これが確定すると天井が見える。**最優先。**

2. **現在の空き施術枠**
   担当者マスタには5名（五十嵐 / ゆう / ショル / 小幡 / 山崎）。
   理論上限は 5 × 25 = 125人。**実際の稼働と空きが何枠あるかで、集客の緊急度と採用の順序が変わる。**
   ここが埋まっているなら、集客より先に採用。

3. **顔なしコンテンツでも数字が出るか**
   → Bの生死を分ける。立ち上げ期の設計で検証する（→ `03-顔出し段階設計.md`）。

4. **家族がどの言葉で検索・反応するか**
   「訪問マッサージ」の認知が1割なら、その語では届かない。
   実際に反応する入口の言葉は、投稿データからしか分からない。

5. **商圏外フォロワーの比率**
   全国リーチのうち地元がどれくらいか。低すぎると患者転換が成立しない。
   Instagramのインサイト（地域データ）で測れる。

6. **訪問マッサージの知名度が、看護師の労働市場に届くか**
   将来の訪問看護参入の前提。**「名前が売れたから」ではなく「看護師が採れる目処が立ったから」で判断する。**

## 7. 意識的に選んだ立ち位置

同じ出来事から2つの解釈ができるので、どちらを自分の実績とするかを先に決めておく。

- ❌ 「講座を売った実績」 → この実績で入れる次の畑は、たいてい「講座を売る商売」
- ⭕ **「業界の誰もできなかった直接集客を、ゼロから成立させた実績」**

後者を持っていれば、別の畑にはもっと真っ当な形で入れる。
